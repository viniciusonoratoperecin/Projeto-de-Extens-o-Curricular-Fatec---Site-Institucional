# Site Institucional — Cristiano Viana | Psicólogo Clínico

> Projeto de extensão curricular, sem fins lucrativos, desenvolvido para fortalecer a presença digital e a comunicação institucional do psicólogo clínico **Cristiano Viana (CRP 06/78037)**.

## Sobre o projeto

Este repositório reúne o desenvolvimento do site institucional de Cristiano Viana, psicólogo clínico da região de São José do Rio Preto/SP. O projeto foi realizado de forma voluntária como atividade de extensão curricular do curso de **Informática para Negócios da Fatec Rio Preto**.

A iniciativa conectou necessidades reais de uma empresa da área de saúde mental a competências técnicas, administrativas e comunicacionais, com foco em uma presença digital profissional, clara, acolhedora e coerente com a atuação clínica.

## Contexto acadêmico

O trabalho integra as disciplinas:

- **Informática e Negócios** — aplicação de fundamentos de desenvolvimento web, organização de processos e solução de uma demanda empresarial real;
- **Comunicação e Expressão** — elaboração, revisão e adequação de textos institucionais, priorizando clareza, coesão, acessibilidade e comunicação ética com o público.

## Objetivos

- Criar um site institucional responsivo e de navegação simples;
- Apresentar os serviços, a atuação profissional e os canais de contato do psicólogo;
- Traduzir a identidade e o posicionamento profissional para o ambiente digital;
- Aplicar boas práticas de redação institucional e copywriting ético para saúde mental;
- Documentar processos administrativos e informações estratégicas da empresa;
- Proporcionar experiência prática interdisciplinar aos estudantes envolvidos.

## Público-alvo

O site foi pensado para pessoas que buscam atendimento psicológico, desejam conhecer o profissional, compreender sua abordagem de trabalho e encontrar formas confiáveis de realizar o primeiro contato.

## Funcionalidades e entregas

- Página inicial institucional;
- Apresentação profissional do psicólogo;
- Organização de informações sobre atendimento e serviços;
- Seções de contato e direcionamento para canais oficiais;
- Layout adaptável para celulares, tablets e computadores;
- Textos institucionais produzidos e revisados para o público-alvo;
- Organização de documentação e materiais administrativos do projeto.

## Tecnologias utilizadas

- HTML5;
- CSS3;
- JavaScript;
- Git e GitHub para versionamento e colaboração.

## Processo de desenvolvimento

1. Levantamento inicial das necessidades do profissional;
2. Coleta e organização de informações institucionais;
3. Planejamento da estrutura de conteúdo e das páginas;
4. Produção e revisão dos textos;
5. Desenvolvimento da interface em HTML, CSS e JavaScript;
6. Testes de navegação, responsividade e legibilidade;
7. Organização dos documentos administrativos e entrega do projeto.

## Princípios de comunicação e ética

Por tratar-se de um projeto ligado à área de saúde mental, a comunicação foi orientada por princípios de responsabilidade e respeito ao público:

- Linguagem clara, respeitosa e acolhedora;
- Não realização de diagnósticos, prescrições ou orientações clínicas pelo site;
- Não utilização de promessas de resultado;
- Respeito à imagem, à privacidade e à confidencialidade;
- Uso responsável de informações institucionais e profissionais.

## Acessibilidade e responsividade

O projeto busca oferecer uma experiência de navegação inclusiva e consistente, considerando:

- Hierarquia visual e textual clara;
- Boa legibilidade;
- Navegação intuitiva;
- Compatibilidade com diferentes tamanhos de tela;
- Estrutura semântica em HTML sempre que aplicável.

## Como executar localmente

Como se trata de um site estático, basta abrir o arquivo `index.html` em um navegador.

Para uma experiência de desenvolvimento mais adequada, recomenda-se utilizar uma extensão de servidor local, como o Live Server do Visual Studio Code.

```bash
git clone <URL_DO_REPOSITORIO>
cd <NOME_DO_REPOSITORIO>
```

Em seguida, abra o arquivo `index.html` no navegador ou inicie um servidor local.
